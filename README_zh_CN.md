
# Dinox 同步（思源笔记）

[English](./README.md)

将 [Dinox](https://dinoai.chatgo.pro) 笔记同步到思源笔记，也可以把思源文档推送回 Dinox。

## 最新更新（v1.1.0）

- 迁移到新的**分页游标增量同步接口**，按每条笔记的更新时间推进游标，增量更准确、内存占用有界。
- 正文改为**客户端 Mustache 模板渲染**，保存与同步前都会做语法校验。
- 新增**按卡片盒过滤同步范围**、**重置同步时间范围**、每日汇总**块引用/块嵌入**两种链接样式。
- **元数据全面块属性化**：思源没有 frontmatter，不再向正文写入 YAML，「忽略同步」「保留属性」均基于块属性。

完整记录见 [CHANGELOG.md](./CHANGELOG.md)。

## 快速开始

1. 在思源中新建一个空笔记本，复制它的**笔记本 ID**
2. 打开插件设置，填入 **笔记本 ID** 和 Dinox 应用中的 **Token**
3. 点击顶栏的 **Dinox 同步** 图标 → 「同步 Dinox 到思源」

笔记会写入所选笔记本下的 `Dinox Sync` 目录（可自定义）。

## 核心功能

### 从 Dinox 同步到思源（拉取）

- **增量同步**：每次只拉取**上次同步之后有变动的笔记**，基于每条笔记的 `updateTime` 作为游标，避免漏同步或时区偏移。
- **分页流式拉取**：按页拉取、逐页处理，内存占用有界，适配桌面 / 移动 / 浏览器端。
- **客户端模板渲染**：接口只返回结构化数据，正文在本地按 Mustache 模板渲染，展示完全由你掌控。
- **删除同步**：Dinox 端删除的笔记会在思源端一并移除（仅增量同步时生效）。
- **失败不推进游标**：任意一条笔记处理失败都不会推进同步游标，下次会重试，绝不丢数据。

**触发方式：**

- 顶栏 **Dinox 同步** 图标菜单
- 命令面板搜索「同步 Dinox 到思源」
- 开启自动同步后每 30 分钟自动拉取

### 从思源推送到 Dinox（推送）

| 操作 | 说明 |
|---|---|
| **智能同步到 Dinox** | 有 `noteId` 则更新，无则创建，自动判断 |
| **创建到 Dinox** | 将当前文档作为新笔记创建到 Dinox |
| **发送选中文本到 Dinox** | 将编辑器中选中的文本创建为一条新笔记 |

以上操作可通过顶栏菜单、文档标题图标菜单或命令面板触发。文档的 Dinox 元数据保存在思源块属性 `custom-dinox-*` 中。

## 目录结构

同步的笔记按设置分层写入不同的 HPath 目录，每一层都可选：

```
Dinox Sync/            ← 同步根目录（可自定义）
 └── note/             ← 按类型分组（可关闭）
      └── 我的卡片盒/    ← 按卡片盒分组（可关闭）
           └── 2024-03-15/   ← 按日期嵌套（可选平铺）
                └── 我的笔记
```

- **同步根目录**：根目录名，默认 `Dinox Sync`
- **按类型分组**：笔记（note）与素材（crawl/material）分到不同子目录；类型直接取自接口，无需模板包含 `{{type}}`
- **按卡片盒分组**：按笔记所属卡片盒名再分一层子目录
- **目录布局**：按日期嵌套 `YYYY-MM-DD` 子目录，或平铺

## 文件命名

支持 `noteId` / 标题 / 创建时间 / 标题+日期 / 自定义模板五种方式。自定义模板可用变量：`{{title}}`、`{{createDate}}`、`{{createTime}}`、`{{noteId}}`。

## 同步范围（按卡片盒过滤）

开启后，只同步选中的卡片盒（含其子卡片盒）中的笔记：

1. 勾选「按卡片盒过滤同步范围」
2. 点击「刷新卡片盒列表」加载你的卡片盒
3. 勾选需要同步的卡片盒即可

## 内容模板

拉取到的结构化数据在本地按 **Mustache 语法**渲染。渲染结果中的 frontmatter 会被剥离并转存为思源块属性，正文写入文档，因此思源文档保持干净、元数据可用属性面板查看与 SQL 查询。

默认模板：

```yaml
---
title: {{title}}
noteId: {{noteId}}
type: {{type}}
tags:
{{#tags}}
    - {{.}}
{{/tags}}
zettelBoxes:
{{#zettelBoxes}}
    - {{.}}
{{/zettelBoxes}}
audioUrl: {{audioUrl}}
createTime: {{createTime}}
updateTime: {{updateTime}}
---

{{content}}
```

保存模板时会做语法校验，语法错误会拒绝保存；同步前也会再次校验，模板损坏时会中止同步而不是写入残缺内容。含音频的笔记会自动插入可播放的 `<audio>` 元素。

## 每日汇总

开启后，每次同步会把当天同步的笔记链接汇总到对应日期的每日汇总文档中：

| 设置项 | 说明 | 默认 |
|---|---|---|
| 启用每日汇总 | 总开关 | 关闭 |
| 每日汇总笔记本 ID | 为空时复用主同步笔记本 | 空 |
| 每日汇总目录 | 例如 `Daily Notes/Dinox` | `Daily Notes/Dinox` |
| 标题 | 受管区域上方标题 | `## Dinox Notes` |
| 新增位置 | 插入到顶部 / 底部 | 底部 |
| 链接样式 | 块引用 `((id))` 或块嵌入（显示内容） | 块引用 |
| 包含内容预览 | 链接下附带一行摘要 | 关闭 |
| 不存在时自动创建 | 日期文档缺失时是否自动创建 | 开启 |

## 元数据与保护本地修改

思源没有 frontmatter，笔记的元数据（`noteId`、类型、标签、时间、音频地址等）统一保存在**思源块属性**（`custom-dinox-*`）中，可在文档的「属性」面板查看，也可用 SQL 查询。插件不会向正文写入任何 YAML，文档正文始终干净。

- **忽略同步**：给文档添加块属性 `custom-ignore_sync = true`（属性名可在设置中自定义），该文档会跳过同步覆盖。
- **保留属性**：你手动添加的 `custom-` 块属性同步时**默认就会保留**；如需额外保护某个属性名不被同步覆盖，在「保留的块属性」中填入即可（逗号或换行分隔，自动加 `custom-` 前缀）。

> 进阶：若需要表格化 / 类型化的元数据，可在思源中用「属性视图（数据库）」把这些文档聚合成一张表；块属性可直接作为数据库字段来源。对同步元数据而言，块属性已足够且更轻量。

## 重置同步

在设置底部选择重置范围（昨天 / 3 天前 / 1 周前 / 1 个月前 / 全部）后点击「重置」，下次同步会从对应时间点重新拉取。适用于更换模板或目录规则后需要重跑历史笔记的场景。

---

## 快捷键 & 自动同步

- 可为「全量同步」「当前文档同步」「创建到 Dinox」设置自定义快捷键。
- 开启自动同步后每 30 分钟自动执行一次增量拉取。

---

## 隐私与网络

插件需要 Dinox Token 才能使用。Token 保存在思源插件配置中，不会写入同步的笔记。插件通过 `aisdk.chatgo.pro` 拉取 / 创建 / 更新 Dinox 笔记，不包含遥测、广告或自动更新。

完整变更记录见 [CHANGELOG.md](./CHANGELOG.md)。
